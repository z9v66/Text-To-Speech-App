# Text-to-Speech Pro 🎙️

A modern and interactive desktop application for converting text to speech, built with **Python**, **pyttsx3**, and **CustomTkinter**.

---

## Features ✨
- **Modern GUI:** Clean, beautiful dark/light interface powered by `CustomTkinter`.
- **Speech Speed Control:** Adjustable slider to control how fast or slow the speech is (100 - 300).
- **Volume Level Control:** Adjustable slider to easily manage volume intensity (0% - 100%).
- **Modular Architecture:** Clean separation of concerns between backend synthesis logic (`voice.py`) and the frontend UI (`main.py`).

---

## Tech Stack 🛠️
- **Python 3.x**
- **CustomTkinter** (for the modern user interface)
- **pyttsx3** (offline text-to-speech conversion engine)
